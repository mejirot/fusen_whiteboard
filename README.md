# 付箋ホワイトボード

付箋を自由に貼り、矢印で結び、矢印付近にラベルを置けるローカル完結のホワイトボードです。

## 使い方

```bash
npm install
npm run dev
```

## 操作

- **付箋追加**: ツールバー、またはキャンバス空白をダブルクリック
- **編集**: 付箋をダブルクリック
- **色**: 付箋を選択して色スウォッチ
- **矢印**: 付箋のハンドルからドラッグ
- **矢印ラベル**: 矢印付近のラベルをダブルクリック
- **選択**: 空白をドラッグ（Shift で複数選択）
- **パン**: 中ボタン / 右ボタンドラッグ
- **ズーム**: ホイール
- **Undo / Redo**: `Ctrl+Z` / `Ctrl+Y`（Mac は `Cmd`）
- **削除**: `Delete` / `Backspace`、またはツールバー
- **保存**: 自動で `localStorage` に保存。JSON の書き出し / 読み込みも可

## 技術

Vite + React + TypeScript + `@xyflow/react` + Zustand。バックエンドなし。
